## 1. 安装与打开

- [ ] **RPK 装得上**：走 AstroBox（手环「设置 → 系统操作 → 连接新手机」→ 电脑 AstroBox 登录小米账号配对 →「安装快应用」选本 RPK）。
- [ ] **手环页打得开**：导航环页面能进入，显示「暂无导航 / 连接中」等初始态。
- [ ] **（若用 aiot 2.0.5 路径）** RPK 是否被 Vela 5.0 拒绝安装或打开即闪退？ → 若被拒，改用 hap 2.1.0 路径。

## 2. 手机 ↔ 手环 互联（最关键）

- [ ] **导航帧能收到**：高德开始步行 / 骑行导航后，手环是否显示转向箭头 + 距离 + 路名？
- [ ] **AAR 1.4 与 Vela 5.0 互通**：若手环一直「连接中」、收不到帧，说明官方 `xms-wearable-lib_1.4_release.aar`（原作者针对 Band 9）在 Vela 5.0 上 `sendMessage` 通道可能不通，需向小米要更新的 interconnect SDK。
- [ ] **证书一致**：RPK 与 APK 是否用同一份 `app/signing` 证书（hap 版脚本已自动复制 `app/signing` 证书到 `band-app/sign/debug` 并校验）。若两边各生成一份，互联会失败。

## 3. 显示与交互

- [ ] 转向图标清晰（本 fork 已把图标放大到 245×245，避免运行时放大发虚）。
- [ ] 距离 / 路名文字可读、排版不被裁切（336×480 屏）。
- [ ] 出现新转向时手环震动一次；步行距转弯 30m / 骑行 100m 再提醒一次。

## 4. 原作者标注「未真机验证」的项（本次同样未验证）

- [ ] 骑行模式的真实导航（协议与单测有，真机未跑）。
- [ ] 转向与临近提醒的震动手感（已实现，体感未专门验证）。
- [ ] 连续 30 分钟以上锁屏 / 口袋场景、手环运动记录中被顶掉的行为、长时间空闲后后台拉起。
